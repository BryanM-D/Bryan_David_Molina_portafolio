# Guía corta para entregar

## 1. Personaliza
node -v
## 2. Prueba
```bash
npm install
npm run dev
npm run lint
npm run build
```

## 3. Sube a GitHub
Nombre requerido del repositorio:
`nombre-apellidos-portafolio`

## 4. Despliega
Importa el repositorio en Vercel y configura:
`nombre-apellidos.vercel.app`
